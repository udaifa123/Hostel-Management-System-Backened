# Hostel Management System – Backend

## Overview

This repository contains the backend API for the Hostel Management System built using **Node.js and Express**.
It handles business logic, authentication, and database operations for managing hostel data.

---

## Key Features

* RESTful API architecture
* Authentication and authorization
* Role-based access control
* CRUD operations (Users, Rooms, Data)
* Secure API endpoints
* MongoDB database integration

---

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

---

## API Endpoints (Overview)

### Authentication

* POST /api/auth/register
* POST /api/auth/login

### Users

* GET /api/users
* POST /api/users

### Rooms

* GET /api/rooms
* POST /api/rooms

---

## Getting Started

```bash
git clone https://github.com/udaifa123/Hostel-Management-System-Backened
cd Hostel-Management-System-Backened
npm install
npm run dev
```

Server runs at: http://localhost:5000/
